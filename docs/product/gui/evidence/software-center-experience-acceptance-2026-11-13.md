# 软件中心统一体验验收 · 2026-11-13

本次交付以[软件中心](../software-management.md)为产品说明，以
`app-gui-product-contract.json#pages.app_management` 为行为合同。
Framework 提供使用入口和知识范围；App 持有产品、页面和图标资产合同；Studio 复用 DSH 页面、导航、设置和现有生命周期动作。

## 已完成的行为

- 日常分区统一为软件、更新、共享资源；软件源、运行组件通过管理入口访问。
- 可用软件在列表和详情提供“开始使用”。智能体进入任务输入，MiniApp 使用实时目录中声明的只读启动器；缺少必要输入时保留目标并展示输入项。
- 安装、修复和共享资源配置保留所选软件，回读后可继续使用；卸载不会触发安装后的继续使用提示。
- 设置只链接到共享资源管理面，保留独立网页端的配置。Obsidian/Markdown 接入支持原生目录选择和 owner 提供的范围选项，授权仍由原来的 revision 与确认合同管理。
- 同一软件源的授权问题按来源合并，展示受影响软件；独立运行故障和安装冲突保留。普通更新、未知状态及未使用的可选资源不计为故障。
- 当前激活安装优先显示版本、开发版或发布版及路径；其他安装折叠。位置操作只在文件管理器中显示路径，切换、解除和卸载继续使用原 owner 的动作。
- 现有 OPL PNG 图标保留，打包索引由 App 资产清单生成并校验摘要，不参与软件准入或生命周期判断。
