## Evidence Work

The conformance matrix records unverified pixels, installed paths and releases
for source-implemented features, including subagent activity, Scheduled Tasks,
Review, accessibility, Package contributions and Storage. Their remaining axes
do not imply missing source or justify another scheduler, client, registry,
annotation store or lifecycle service.

Computer Use Standard-online/Full-offline parity, new packaged Codex identity,
clean-host first run, App updates and public asset currentness must be qualified
for the exact release operation. Historical maintainer-host or VM receipts do not
close new cohorts. Use the [release guide](../delivery/release/README.md) and
[testing reference](../testing/README.md) for that work.

## Closure

When an implementation gap closes, update its topic reference and conformance
evidence, remove the completed row here, and retire the completed plan after
transferring unique constraints. Execution transcripts and next-agent prompts
belong in task history. Follow the [documentation lifecycle](../docs_portfolio_consolidation.md).
