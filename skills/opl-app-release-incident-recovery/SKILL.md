# OPL App Release Incident Recovery

This explicit legacy entry uses the same App-owned [release SOP](../../docs/delivery/release/stable-release-sop.md) as `opl-app-release`. Resolve the real path when installed through a symlink, locate the App repository, then read the current-run monitoring and recovery sections.

Preserve the user's scope and existing authorization. Reconcile the current owner before taking action, and use the SOP's existing controller and checkpoint recovery path. A status-only request remains read-only. This compatibility entry defines no separate execution rules, credentials, completion criteria or release authority.
